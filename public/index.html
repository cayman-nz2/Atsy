1 · Contact details sit in the page header

Critical

Header and footer bands are often skipped entirely, so an email and phone can vanish. Move them into the body of the first page.

page 1 · header band · "priya.raman@example.com"

+1 point · check B06

2 · The layout is two columns

Critical

The file stores this text in an order that runs across the gutter, so extraction interleaves the columns — that is the machine view, not a simulation. Use one column.

gutter at x=138pt · both sides hold >15% of the text

+6 points · check P02

3 · Skill ratings are pictures

Major

Rating dots extract as nothing, so none of these skills is recorded — and reviewers distrust self-rated bars. Write plain skill names instead.

3 glyph runs next to skill terms · 0 characters extracted

+2 points · check P10

4 · Two different date formats

Major

"March 2023 — now" and "06/2019 - 02/2023" belong to different families, so tenure is computed wrong. Use one: Mar 2023 – Present.

page 1 · "March 2023 — now" · "06/2019 - 02/2023"

+4 points · check C02

What you get back

A score you can argue with

Every point Atsy takes off is attached to a finding, with the evidence from your file and the fix written as an instruction. The score is deterministic — the same CV always scores the same, because no language model touches the scoring — and every check is published: read the full rubric.

What gets checked

  • Can the text be extracted at all
  • Reading order, columns, tables, headers
  • Contact block, dates, work history
  • Impact, action verbs, quantified results
  • Skills, and how findable they are

What you get

  • A score with five pillar breakdowns
  • Fixes ordered by the points they win back
  • The exact text a parser extracts
  • Per-engine parse risk, with reasons
  • Role fit against a job description

What happens to your file

  • Encrypted before it is stored
  • Deleted automatically within 24 hours
  • Never readable by anyone at Atsy
  • Never sent to an AI with your name on it
  • Delete everything in one click, any time

What we keep, and for how long

What Atsy is not. No applicant tracking system publishes a candidate score, and every one of them parses differently — so nobody, including this tool, can tell you "your Workday score". Atsy reports how readable your file is and where it will break, using checks you can read for yourself. Any number you see here is one Atsy worked out from your own file.
